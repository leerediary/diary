# 日记

一个本地优先的个人日记应用 —— 日记 / 习惯 / 任务 / 番茄钟，数据只存在你自己的手机里。

无需注册、无服务器、无云同步。装到 iPhone 主屏幕后像独立 app 一样离线可用（主屏幕图标显示「日记」）。

---

## 怎么安装（iPhone Safari）

1. 用 Safari 打开：
   **`https://leerediary.github.io/diary`**

2. 点底部 **分享** 按钮（方框 + 向上箭头）

3. 往下滑，选 **添加到主屏幕**

4. 确认名称「日记」→ 点右上角 **添加**

5. 回到主屏幕，点「日记」图标打开，之后可以离线使用

> 如果没看到「分享」按钮，可以在打开链接后往下滑一点，底部工具栏会出现。app 内也会在底部显示一次性提示横幅作为兜底提醒。

---

## 数据在哪，安全吗

所有数据都存在你手机的浏览器本地存储（IndexedDB）里，不上传到任何服务器。不同设备的数据互相隔离 —— 即使别人也安装同一个链接，看到的是他们自己的数据，和你的完全无关。

---

## 重要：定期备份

装到主屏幕的 PWA **不会**被 Safari 自动清理，但如果手机存储极度紧张，系统仍可能清掉浏览器本地数据（IndexedDB）。

所以请定期使用 app 内的 **导出** 功能保存一份备份文件：

- 打开 app → 进入导出页面
- 下载的 `.json` 文件就是完整数据备份
- 换设备或清缓存后，用 **导入** 功能恢复

App 本身不会主动提醒备份，需要你自己养成习惯。
